# People Success Services Guide

Static, responsive Boldr People Success website for GitHub Pages.

## Files

- `index.html` — one-page website
- `assets/styles.css` — responsive Boldr-branded styling
- `assets/script.js` — navigation, Quick Finder, reveal effects, and image zoom
- `assets/images/` — local logo, QR, platform, and source presentation assets

No framework, package manager, or build step is required. Upload the contents to the repository root and publish from GitHub Pages.

The CSS references the official Inter and Roboto Mono font families with local system fallbacks. No font files are bundled.
