# People Success Services Guide

Static website built from the People Success Services Guide presentation.

## Structure

- `index.html` — one-page website
- `assets/styles.css` — responsive Boldr-branded styling
- `assets/script.js` — mobile navigation, scroll highlighting, and lightweight reveal effects
- `assets/images/` — logo, learning platform artwork, QR code, and visual assets from the source presentation

No package manager, framework, build process, or external dependency is required.

## Run locally

Open `index.html` directly in a browser, or start any simple static web server from this folder.
